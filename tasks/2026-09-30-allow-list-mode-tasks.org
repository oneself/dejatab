* Notes

- There is no build step and no package manager. Chrome loads
  [[file:../src/][src/]] as it is.
- Run the tests with ~node --test~ from the repository root, bare. A single
  file: ~node --test test/settings.test.js~. Passing the directory fails.
- Only the pure functions of [[file:../src/settings.js][src/settings.js]] are
  unit tested. The worker and the options page are checked by hand in 5.0.
- Requirement numbers in brackets refer to the allow-list PRD. Read the TSD
  section named in a sub-task before writing its code.
- Task 1.0 goes first: it defines ~isAllowed~ and ~actsOn~, which 2.0, 3.0 and
  4.0 call by name. After it lands, 2.0, 3.0 and 4.0 can be done in parallel.
  3.0 and 4.0 both edit [[file:../src/options.js][src/options.js]], in
  different functions.
- Never let the new mode close a tab on a site the user did not allow. Every
  uncertain path ends with DejaTab doing nothing [TSD, Error Handling].
