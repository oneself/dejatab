* Notes

- There is no build step. Chrome loads the files in [[file:../src/][src/]] as
  they are, and publishing is a zip of the repository's extension files.
- Tests run with Node's own runner, no framework installed: ~node --test~ for
  everything, ~node --test test/rules.test.js~ for one file. Node 18 or later.
- Only [[file:../src/rules.js][src/rules.js]] and the pure functions of
  [[file:../src/settings.js][src/settings.js]] are unit tested. Everything else
  is checked by hand against the checklist in 7.0, because it cannot run outside
  Chrome.
- Load the extension while working on it at ~chrome://extensions~ with developer
  mode on, "Load unpacked", pointing at the repository root. The reload button
  there picks up every change except a manifest change, which needs a full
  reload of the extension.
- Requirement numbers in brackets refer to the PRD. Read the TSD section named
  in a sub-task before writing that sub-task's code.
- Never let a failure close a tab. Every uncertain path in this extension ends
  with tabs staying open [TSD, Error Handling].
